A Neural Network in Pure CSS, Training Included

CSS already knows sin() — it ships in every modern browser, free of charge. The tank below contains a two-layer neural network (1 → 5 → 1, ReLU) that has to learn the sine wave anyway. And this time nobody did its homework for it: when this page loads, your browser runs 80 steps of gradient descent — forward passes, gradients, momentum, the lot — entirely inside the CSS cascade. The 🐟 swims on the real sin(x). The 🐠 swims on the network’s output, step by step, as it learns. The bar between them is the error. There is no JavaScript on this page.

The training loop is the DOM

CSS is famously “Turing-complete” — with an asterisk: it has no clock. A custom property can’t update itself; --w: calc(var(--w) - …) is a cycle, and the cascade politely refuses. So this page does what hardware designers do when they can’t loop: it unrolls. The tank contains 80 nested <div>s — one per training step — and every element computes its weights from the weights it inherits from its parent: 

<div class="st a">   <!-- computes θ₁ from θ₀  -->
  <div class="st b"> <!-- computes θ₂ from θ₁  -->
    <div class="st a"> <!-- computes θ₃ from θ₂ … 80 levels deep -->

Self-reference is dodged by ping-ponging two families of properties: even generations write --u1a from --u1b, odd generations write --u1b from --u1a. Which means the entire trainer is two CSS rules — .st.a {…} and .st.b {…} — and the DOM runs them 80 times by selector matching. Each generation is one honest step of full-batch gradient descent with momentum: 12 forward passes (max(0, wx+b) is ReLU), residuals against sin(), gradients with the ReLU derivative as sign(), momentum, update: 

.st.a {
  /* forward: --h3x7 = relu(u₃·x₇ + p₃), for all 5 neurons × 12 samples */
  --h3x7: max(0, var(--u3b) * 0.5416666666666666 + var(--p3b));
  /* residual at sample 7: net(x₇) − sin(2πx₇) */
  --r7: calc(var(--v1b)*var(--h1x7) + … + var(--qb) - 0.13052619222005157);
  /* momentum + update for u₃  (0.05 = lr · 2/N; sign() is ReLU′) */
  --mu3a: calc(0.9 * var(--mu3b) - 0.05 * var(--v3b) *
          (var(--r1)*sign(var(--h3x1))*0.041666… + … ));
  --u3a: calc(var(--u3b) + var(--mu3a));
  /* … ×5 neurons, ×3 parameter kinds, +1 output bias */
}

Every arithmetic operation of training happens in your style engine, at page load, in about a millisecond. The only numbers shipped in this file are the random initial weights — and you can watch how little they know: that’s the step-0 fish.

The replay is just visibility

Each step element carries a full-width “rider” layer that knows that step’s weights by inheritance. A rider computes the network’s output at the current swim position — --ys is five max() calls — and puts the 🐠 there with a transform. A staggered animation-delay: calc(var(--si) * 0.16s) reveals each rider for its 0.16-second slot, so the fish you watch is hopping along the actual optimization trajectory your browser just computed: 13 seconds from flailing to competence, plus a held bow at step 80, forever, on loop.

The teacher was born knowing

.fish.teacher {
  --yt: calc(sin(var(--x) * 2 * pi));  /* that’s it. that’s the fish. */
}

Trigonometry landed in CSS in 2023, so the 🐟 gets the answer sheet for free. The dotted wave is 64 static dots, each evaluating sin() at its own position. Talent is not fairly distributed in this tank.

The scoreboard doesn’t cheat either

The loss in the corner is not a caption — each rider recomputes its step’s mean-squared error from its own weights: twelve forward passes compared against sin(), squared with pow(), averaged in one calc(). The digits reach the screen through the CSS counter trick: 

.r {
  --L: calc((pow(/* net(x₁) */ - sin(x₁ · 2π), 2) + … ) / 12);
  --Ld1: mod(round(down, calc(var(--L) * 10), 1), 10);  /* tenths digit */
}
.r::after {
  counter-reset: ep calc(var(--si)) d1 calc(var(--Ld1)) /* … */;
  content: "step " counter(ep) "  ·  loss " /* … */;
}

Fine print: the repetitive program text (80 nested divs, two big rules) is printed by generate.mjs, which also picked the hyperparameters and the random seed offline — printing text is allowed; it’s the browser that does every multiplication. Between the 80 computed steps nothing is interpolated: what you see hop is the real discrete trajectory. If you’ve asked your OS for reduced motion, the cascade still trains the network — you just get the graduation photo instead of the ceremony. Needs @property, trig, pow(), sign() — all Baseline as of 2024.
